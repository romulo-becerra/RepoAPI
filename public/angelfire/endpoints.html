Catalogo de Endpoints API v1

Ruta publica: /angelfire/endpoints.html. Base URL recomendada para pruebas locales: http://localhost:3001.

Publico: sin Authorization Customer: solo su propia cuenta y operaciones de cliente Cashier: operaciones de caja y atención Management: manager/admin con reportes y gestión Admin: control total del sistema Multipart: usar form-data (archivo)

Matriz de permisos del sistema

Rol Operaciones visibles
customer Cuenta propia, transferencias, pagos, movimientos y consultas de préstamo.
cashier Depósitos, retiros, atención de cuenta y operaciones de caja; sin administración de usuarios.
manager Reportes, gestión, consultas de usuarios y cuentas, originación de préstamos y auditoría.
admin Todo lo anterior más creación, eliminación, bloqueo y manejo de usuarios y roles.
Metodo Ruta Auth Descripcion Query / Body minimo Ejemplo rapido

Headers base sugeridos

Accept: application/json Content-Type: application/json Authorization: Bearer <token> (solo endpoints protegidos)

Notas para Postman/Insomnia

  • Crea variable {{baseUrl}} con valor http://localhost:3001.
  • Para endpoints de manager usa token de usuario con rol manager.
  • Para subir archivo usa form-data y campo file.
  • Descarga de plan de pagos devuelve CSV en text/csv.
